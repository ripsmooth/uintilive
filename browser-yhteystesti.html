Swimify – selainyhteyden testi

Tämä on erillinen testisivu. Se ei muuta nykyistä grafiikkaa eikä ohjauspaneelia. Testi yrittää tehdä GraphQL-pyynnön suoraan selaimesta Swimifyn rajapintaan.

Avain käsitellään vain tämän sivun muistissa. Sitä ei tallenneta eikä lähetetä muualle kuin Swimifyn GraphQL-osoitteeseen. Älä lisää avainta GitHub-koodiin.
Testiä ei ole vielä tehty.
Odottaa testiä…
Miten tulosta tulkitaan?
  • HTTP 200 ja JSON-vastaus: selain pystyy hakemaan tiedot suoraan. Sen jälkeen voidaan rakentaa erillinen selainpohjainen grafiikkatesti.
  • CORS-virhe: Swimify ei salli pyyntöä GitHub Pages -sivun alkuperästä. Selainpohjainen grafiikka ei silloin voi hakea tietoja suoraan tältä sivulta.
  • HTTP 403 / Cloudflare: myös selaimesta tehty pyyntö estyy tällä sivun alkuperällä.
